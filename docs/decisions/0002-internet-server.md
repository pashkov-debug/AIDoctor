# ADR-0002: Единый PostgreSQL backend

Статус: принято для следующей версии.
Для совместной работы врача и пациента используется единая серверная база PostgreSQL.
SQLite не применяется ни в приложении, ни в интеграционных тестах.
Весь доступ к пациентам проходит через защищённый API с авторизацией.
Для медицинских данных требуется отдельное развёртывание, аудит и проверка ИБ.
