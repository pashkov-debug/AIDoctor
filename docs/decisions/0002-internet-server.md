# ADR-0002. Централизованная история при работе через интернет

Статус: принято для дальнейшей реализации.

Врач и пациент работают из разных сетей. Источник истины — серверная БД. Клиенты хранят только производный кэш. Внешний LLM получает данные через серверный шлюз и не владеет базой. PostgreSQL — целевая рабочая СУБД; SQLite допускается для локальных тестов. Смена схемы через Alembic, перенос существующих записей — отдельный проверяемый процесс.

Последствия: требуется серверное RBAC, TLS, аудит, защищённые вложения, мониторинг, резервное копирование и регуляторная проверка. До их завершения публичное развёртывание запрещено.
